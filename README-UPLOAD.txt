GitHub Pages setup
==================
Your repository: commercial-analytics-portfolio

1. Open the repository's Code tab.
2. Click Add file > Upload files.
3. Upload index.html, Commercial_Analytics_Portfolio.pdf, and the six page images from the assets folder, preserving the assets/ directory structure. The simplest way to preserve paths is to drag the complete assets folder into the GitHub upload area (supported in desktop Chrome).
4. Click Commit changes.
5. Under Settings > Pages, keep Source: Deploy from a branch, Branch: main, Folder: /(root).
6. Wait for deployment, then open:
   https://mahdi-rajaei.github.io/commercial-analytics-portfolio/
